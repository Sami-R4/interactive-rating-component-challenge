# Frontend Mentor - Interactive Rating Component

A solution to the [Interactive Rating Component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/interactive-rating-component-koxpeBUmI).

## Overview

This project is an interactive rating component that allows users to select a rating from 1 to 5 and submit their feedback. After submission, a thank-you message displays the rating selected by the user.

The project was built to practice frontend development fundamentals, including responsive design, DOM manipulation, and JavaScript event handling.

## Features

- Select a rating from 1 to 5.
- Visually highlight the selected rating.
- Submit a rating using the Submit button.
- Display a thank-you screen showing the selected rating.
- Validate the rating selection before submission.
- Responsive layout for mobile and desktop screens.

## Built With

- HTML5
- CSS3
- JavaScript
- Bootstrap

## What I Learned

While building this project, I practised:

- Manipulating the DOM with JavaScript.
- Handling user interactions and click events.
- Managing the selected rating and updating the interface.
- Validating user input before displaying the thank-you state.
- Using Bootstrap alongside custom CSS.
- Creating a responsive user interface.

## Challenges Faced

The most challenging part of this project was implementing the JavaScript interactions, particularly connecting the user's rating selection to the submission process and thank-you screen.

Working through this helped me better understand how JavaScript can make a webpage interactive.

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Sami-R4/interactive-rating-component-challenge.git
   ```

2. Open the project folder:

   ```bash
   cd interactive-rating-component-challenge
   ```

3. Open `index.html` in your browser.

No build tools are required.
